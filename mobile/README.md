# VisionGlyco mobile app

React Native (Expo SDK 57, Expo Router) app that photographs the eye and runs the
VisionGlyco TFLite model **on the phone**. Photos and results never leave the device.

## Features

- **Scan:** camera with a guide circle matching the model's crop, torch and
  front/back toggle, or pick a photo from the gallery
- **On-device inference** with `react-native-fast-tflite`, so it works offline
- **Result screen:** the prediction, what to do next, and the model's measured
  accuracy on unseen patients
- **History:** list of past scans, a trend chart, and delete one or all
- **Model screen:** held-out test metrics, baselines, dataset sizes
- **First-launch notice**, plus a warning if a synthetic test model or a model below
  its accuracy target is installed

## Bundled model

The app currently ships with an **interim model** trained on a public iris dataset
(`../ml/experiments/iridology/`, 90.9% cross-validated accuracy). For each photo the app
crops the iris, estimates the pupil, unwraps the iris into a 201×720 strip
(`src/ml/polar.ts`, identical to `ml/visionglyco/iris_polar.py`), and returns
"Diabetic iris pattern" or "No diabetic pattern".

To rebuild it:

```bash
git clone --depth 1 https://github.com/NaghmeNazer/diabetes-iridology /tmp/iridology
cd ../ml
python experiments/iridology/run_experiment.py --data-zip /tmp/iridology/Data.zip
python experiments/iridology/export_app_model.py --data-zip /tmp/iridology/Data.zip --install-to-app ../mobile
```

## Replace it with your own model

Train one on VisionGlyco data (see `../ml/README.md`) and install it:

```bash
cd ../ml
python train.py --labels data/labels.csv --images-dir data/images --install-to-app ../mobile
```

This copies `visionglyco.tflite` and `model_metadata.json` into `assets/model/` and
regenerates `src/ml/bundledModel.ts`. Then rebuild the app.

## Run

TFLite is a native module, so the app needs a development build. Expo Go will not work.

```bash
npm install
npx expo run:android          # or: npx expo run:ios  (macOS + Xcode)
# or build in the cloud without Android Studio / Xcode:
npx eas-cli@latest build --profile development --platform android
```

After the first build, `npm start` serves JavaScript changes to the installed dev build.

## Checks

```bash
npm run typecheck

```

## Code layout

```
src/app/                 Expo Router screens
  _layout.tsx            root stack + first-launch disclaimer
  (tabs)/index.tsx       home
  (tabs)/history.tsx     history + trend chart
  (tabs)/model.tsx       model accuracy and dataset info
  capture.tsx            camera / gallery capture
  result/[id].tsx        single result
src/ml/
  preprocess.ts          centre crop + RGBA→float32 (mirrors ml/visionglyco/preprocess.py)
  polar.ts               pupil estimate + iris unwrap (mirrors ml/visionglyco/iris_polar.py)
  analyzeEyePhoto.ts     photo → crop/resize → decode → model → prediction
  model.ts               loads the bundled TFLite model and checks its input shape
  interpret.ts           model output → result label; user-facing warnings
  bundledModel.ts        generated by --install-to-app
src/storage/history.ts   on-device scan history
```
